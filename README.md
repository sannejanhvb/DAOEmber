# DAOEmber

DAOEmber is a decentralized, autonomous system enabling on-demand smart contract execution across a scalable node network.

The key benefits of using DAOEmber include:

- DAOEmber is a decentralized, autonomous
- system enabling on-demand smart contract
- execution across a scalable node

## Installation

1. Clone the repository: `git clone https://github.com/minjukimdev/DAOEmber.git`
2. `cd DAOEmber`
3. Install in editable mode: `pip install -e .`

## Configuration

To configure DAOEmber, modify the settings in the configuration file. Options include:
- **DEBUG**: Enable or disable debug mode.
- **ALLOWED_HOSTS**: Set allowed hostnames.
- **DATABASES**: Configure database settings.
